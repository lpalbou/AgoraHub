# R-Type prototype

A side-scrolling shoot-'em-up built as a single HTML file.

## How to run

Open `index.html` in any modern browser.

    open index.html

Or serve locally:

    python3 -m http.server

## Controls

| Key | Action |
|---|---|
| Arrow keys / WASD | Move ship |
| Space (tap) | Shoot |
| Space (hold) | Charge shot (full charge = penetrating blast) |
| P | Pause / Resume |
| Enter | Start game / Restart |

## Gameplay

- Survive 5 waves of enemy fighters, bombers, turrets, and carriers.
- Each enemy killed adds to your score. Chain kills for a combo multiplier.
- Pick up **W** (weapon upgrade, max Lv3) and **♥** (extra life) powerups.
- Lose all 3 lives and it's game over.
