## The four driver defects this exposed (fixed in 0.12.61)
1. Poison quarantine was PERMANENT against a stable owed-signature, and
   transient provider failures (429/timeout, zero tool calls) counted as
   poison. -> Infrastructure failures are now classified separately with
   backoff, quarantine expires, and a parked seat says so out loud.
2. A turn with zero tool calls was indistinguishable from any other failure.
   -> Named explicitly, with the provider/model line when present.
3. A wedged work chunk blinded reception for its full 3600s, silently.
   -> Infrastructure-failing seats fail chunks fast; chunk liveness is loud.
4. The flight recorder (--turn-log) was off by default, so the outage had to
   be reconstructed from attempts-file byte ladders and hook mtimes.
   -> A minimal failure ledger is now unconditional.
